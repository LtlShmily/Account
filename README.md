# 礼金账本小程序

基于微信小程序 TypeScript 基础模板实现的本地礼金账本。当前版本覆盖收取礼金宴席、来宾明细、独立送礼记录、首页累计统计与近期记录。

## 在微信开发者工具中打开

1. 使用微信开发者工具打开项目根目录 `F:\Awork\Account`。
2. 项目配置中的小程序根目录为 `miniprogram/`，TypeScript 编译由开发者工具按 `project.config.json` 配置处理。
3. 首页可进入「收取礼金」或「送出礼金」；收礼记录按宴席归档，送礼记录不关联宴席。

## 数据说明

- 账本数据保存在当前设备的小程序本地存储中，键为 `gift-ledger-v1`。
- 金额以人民币分保存，界面显示为元；卸载小程序或清理本地数据可能导致账本丢失。
- 首期不包含账号、云端备份或跨设备同步。

## 主要目录

- `miniprogram/services/ledger.ts`：数据类型、本地存储、金额与合计函数。
- `miniprogram/pages/`：首页、宴席列表/详情/表单、送礼列表/表单。
- `DEVELOPMENT_PLAN.md`：已确认范围、产品决策、实施进度与持续维护记录。

## 进度

页面和本地数据操作已实现。仍需在微信开发者工具中进行端到端操作和屏幕适配验收；当前执行环境不含微信小程序运行时或 TypeScript 编译器。
